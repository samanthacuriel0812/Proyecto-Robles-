
# Página Web Comunidad Robles - Proyecto Scrum

Este proyecto es una aplicación web desarrollada en **React** como parte de la entrega de la metodología Scrum. Permite gestionar y visualizar la planeación de tareas y eventos de la comunidad.

---

##  Tecnologías Utilizadas

* **React.js** (JavaScript / JSX)
* **CSS3** para los estilos
* **Git & GitHub** para el control de versiones
